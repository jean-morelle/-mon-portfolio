# Portfolio — Jean-Morelle KOUDORO

Portfolio personnel de **Jean-Morelle KOUDORO**, développeur Full Stack spécialisé back-end .NET (C#, ASP.NET Core), basé au Togo.

## Contenu

- **Accueil** : présentation, chiffres clés, téléchargement du CV
- **À propos** et **Compétences** : C#, ASP.NET Core, EF Core, Laravel, PostgreSQL, MySQL, React…
- **Projets** :
  - [GKAS-GROUP](https://gkasgroup.com/) — site client en production (Laravel, MySQL)
  - [DigitalAllianceTogo](https://github.com/jean-morelle/DigitalAllianceTogo) — plateforme e-commerce (ASP.NET Core, PostgreSQL, MediatR)
  - [NunyFood](https://github.com/jean-morelle/NunyFoodWebApi) — commande et livraison de packs alimentaires (ASP.NET Core, React)
  - [GKAS Émargement](https://github.com/jean-morelle/GkasGroupEmargement) — pointage des employés par QR code (ASP.NET Core)
- **Parcours**, **Services** et **Contact** (email, WhatsApp, LinkedIn, formulaire)

## Fonctionnalités

- Thème clair / sombre mémorisé dans le navigateur
- Animations : titre tapé automatiquement, compteurs, apparition au défilement, halo qui suit la souris
- Responsive (mobile, tablette, ordinateur) et accessible (navigation au clavier, `prefers-reduced-motion`)

## Technologies

React 19 · Vite · CSS pur (sans framework)

## Lancer le projet

```bash
npm install
npm run dev      # serveur de développement sur http://localhost:5173
npm run build    # version de production dans dist/
npm run lint     # vérification du code (oxlint)
```
